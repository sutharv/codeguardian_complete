🚀 Getting Started

Follow these simple steps to set up CodeGuardian and start scanning your code for security vulnerabilities.

1

📂 Extract & Navigate

Extract the downloaded zip file and open terminal/command prompt in that folder.

# Extract the zip file first, then: cd codeguardian
2

🐍 Create Virtual Environment

Create an isolated Python environment to avoid conflicts with other projects.

# Create virtual environment python -m venv venv # Activate it (Windows) venv\Scripts\activate # Activate it (Mac/Linux) source venv/bin/activate
3

📦 Install Dependencies

Install all required Python packages including FastAPI, security scanners, and utilities.

# Install main dependencies pip install -r requirements.txt # Install security scanners (IMPORTANT!) pip install bandit semgrep
4

🔑 Set API Key (Optional)

For AI-powered fix suggestions, set your Anthropic API key. Skip this for basic scanning.

# Windows (PowerShell) $env:ANTHROPIC_API_KEY="your-key-here" # Mac/Linux export ANTHROPIC_API_KEY="your-key-here"
5

🚀 Start the Server

Launch the CodeGuardian API server. Keep this terminal window open!

python -m uvicorn src.api.server:app --reload --port 8080

✅ You should see: "Application startup complete"

6

🎯 Start Analyzing!

Server is running! Now click the "Analyzer" tab above to scan your code for vulnerabilities.

🏗️ System Architecture

Understanding how CodeGuardian works under the hood.

🔍

Security Scanners

Multiple scanners work together to detect vulnerabilities.

  • Bandit - Python security linter
  • Semgrep - Multi-language pattern matching
  • Policy Engine - Custom rule evaluation
🧠

LLM Analysis

AI-powered contextual analysis and fix generation.

  • False positive reduction
  • Contextual remediation
  • Security rationale
📋

Policy Engine

Enforces security standards and compliance.

  • OWASP Top 10 (2021)
  • CWE/SANS Top 25
  • Custom organization rules
